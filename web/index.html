⚙️ Project Architecture (Viva Ready)

Frontend

Pure HTML5 + Modern CSS3 with flexbox, CSS grid, glassmorphism card styling, responsive layouts, and zero external npm/node dependencies.

Backend

Pure Standard Java 25 using JDK built-in com.sun.net.httpserver.HttpServer with custom REST route handlers and multi-threaded request processing.

Database

SQL Relational Schema (database.sql) featuring 3 normalized tables (books, members, transactions), foreign keys, and console query logging.
