💾 Relational Database Schema (SQL)

database.sql 
-- 1. BOOKS TABLE
CREATE TABLE books (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(150) NOT NULL,
    author VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL,
    isbn VARCHAR(20) UNIQUE NOT NULL,
    total_copies INT NOT NULL DEFAULT 1,
    available_copies INT NOT NULL DEFAULT 1,
    added_date DATE NOT NULL
);

-- 2. MEMBERS TABLE
CREATE TABLE members (
    id INT AUTO_INCREMENT PRIMARY KEY,
    roll_no VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    department VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    phone VARCHAR(15) NOT NULL,
    join_date DATE NOT NULL
);

-- 3. TRANSACTIONS TABLE (With Foreign Keys)
CREATE TABLE transactions (
    id INT AUTO_INCREMENT PRIMARY KEY,
    book_id INT NOT NULL,
    member_id INT NOT NULL,
    issue_date DATE NOT NULL,
    due_date DATE NOT NULL,
    return_date DATE NULL,
    fine_amount DECIMAL(6, 2) DEFAULT 0.00,
    status VARCHAR(20) NOT NULL DEFAULT 'ISSUED',
    CONSTRAINT fk_trans_book FOREIGN KEY (book_id) REFERENCES books(id),
    CONSTRAINT fk_trans_member FOREIGN KEY (member_id) REFERENCES members(id)
);

🎓 Top College Viva Questions & Answers

For 100 Marks

Q1: How does Java communicate with the browser without external libraries?

Ans: We use standard Java's built-in com.sun.net.httpserver.HttpServer. It binds to port 8080 and registers custom HttpHandler implementations for REST endpoints like /api/books and /api/issue. Frontend JavaScript calls these via standard fetch() API.

Q2: How are relationships represented in the SQL Database?

Ans: The transactions table acts as an associative entity linking books(id) via FOREIGN KEY (book_id) and members(id) via FOREIGN KEY (member_id). This satisfies 3NF (Third Normal Form) and prevents data redundancy.

Q3: What happens to inventory when a book is issued or returned?

Ans: In our Business Logic (DAO/DBManager), when a book is issued, we execute UPDATE books SET available_copies = available_copies - 1 WHERE id = ?. When returned, we increment it back and calculate any overdue fine based on days exceeded beyond the due date.

Q4: Why did we choose this architecture?

Ans: It provides 100% portability. Because no npm, node, or heavy container servers are required, any student or evaluator can run it instantly using just standard Java compiler (`javac`) and JVM (`java`).
